# Inventário do portal de dados abertos do ONS

Gerado em 2026-09-25 a partir da **API de catálogo** do portal (`https://dados.ons.org.br/api/3/action/package_search`, 85 conjuntos) e dos contratos ODCS do MCP oficial (`ONSBR/TIAGO-Dados-Abertos`, 80 contratos), de onde vêm granularidade, recorte e início da cobertura. **Só metadados**: nenhum dado foi baixado para montar esta tabela.

- **Período**: menor e maior ano presentes nos nomes dos arquivos publicados; entre parênteses, o início declarado no contrato do MCP.
- **MCP**: se o conjunto é coberto pelo servidor MCP oficial (ver `docs/mcp_ons.md`).
- **Relevância**: D1 = curtailment, D2 = demanda/carga supervisionada, Ambos, Nenhum. Atribuída pelo time; critérios na coluna "Uso".
- A seleção final do que é baixado está em `Backend/data/catalogo_series_selecionadas.md`.

## Lacunas encontradas

| Lacuna | Situação |
|---|---|
| **Limites de exportação NE e N/NE** | **Não existem no portal.** `programacao_fluxo_controlado` só tem fluxos programados de elos CC, defasadores e interligações internacionais. `ind_confiarb_atls` é mensal/anual. Bloqueia a feature "folga até o limite" do classificador CNF (cortável). Ver STATUS → Bloqueado. |
| **Capacidade instalada de MMGD por subsistema** | **Não existe como série no portal.** A MMGD aparece só como *geração estimada* (`carga-energia-verificada.val_cargammgd`, `balanco_dessem_detalhe.val_ger_mmgd`). Capacidade vem de fora do ONS (ANEEL, BDGD). |
| Carga verificada semi-horária | Não está no bucket S3/CKAN nem no MCP: só pela API REST `https://apicarga.ons.org.br/prd` (desde 2016-01-01, máx. 3 meses por chamada). |
| Base tm solar | Começa em **2024-04** (eólica em 2021-10). Antes disso não há rótulo de curtailment solar. |
| Intercâmbio nacional | Parquet só de 2023 em diante; 2000–2022 só em CSV (o download aceita CSV só para esse conjunto). |
