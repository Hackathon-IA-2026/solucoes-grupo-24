====================
Referência do código
====================

Documentação extraída das **docstrings do próprio código**, pelo
``sphinx.ext.autodoc``. Não é uma segunda descrição que pode divergir da
primeira: é a mesma, lida da fonte.

.. admonition:: Como ler esta seção
   :class: important

   As docstrings do protótipo registram deliberadamente **o porquê** de cada
   decisão, e não apenas o que a função faz — incluindo os erros encontrados
   e corrigidos no caminho. É onde está a justificativa de cada premissa.
